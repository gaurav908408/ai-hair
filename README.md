## ✨ Features

- 📸 Upload your photo from your device.
- 🎨 Choose from multiple hairstyle options.
- 🤖 AI-powered hairstyle transformation.
- 👨 Compare original and transformed photos.
- 📥 Download your generated hairstyle result.
- 🔄 Try different hairstyles.
- 📱 Responsive and user-friendly interface.
- ⚡ Fast and smooth user experience.

## ⚙️ How It Works

**Step 1: Upload Your Photo**

Upload a clear, front-facing photo from your device or gallery.

**Step 2: Choose Your Hairstyle**

Select your preferred hairstyle from the available options.

**Step 3: Generate Your Look**

Let AI generate your hairstyle transformation.

**Step 4: View & Download**

Preview your transformed look and download the result.

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Deployment & Hosting:** Vercel

## 💻 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the root directory and add the required environment variables for your application.

**Note:** Never share or commit your API keys or secret credentials.

### 5. Start Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
